这个目录放 README 首页用到的三张静态 SVG。它们只用 SVG，不依赖图片生成、外链字体或动画，改文案直接编辑文件即可。

| 文件 | 用在哪 | 画布 |
| --- | --- | --- |
| `hero-banner.svg` | 首屏横幅：一句话说明 + 手机 → 协议 → Agent 宿主三段流 | 1200 × 400 |
| `architecture.svg` | 「怎么工作」：Android 客户端 / 协议 / Agent 宿主三列 | 1200 × 560 |
| `security-model.svg` | 「安全边界」：四级审批门 + 我们永远不做 | 1200 × 420 |

## 设计 token

改图时沿用这套值，别单独发明新颜色或新字号：

| 用途 | 值 |
| --- | --- |
| 画布底色 | `#08110E → #0D1A15` 线性渐变 |
| 卡片 / 内层卡 / 浮起层 | `#101C17` / `#12211B` / `#16281F` |
| 描边 | `#22382F`（1.5），强调 `#2E4A3E` |
| 主文字 / 次文字 / 弱说明 | `#F3F7F5` / `#9DB0AA` / `#7E918C` |
| 主色 / 次色 / 警示 / 禁止 | `#34D399` / `#38BDF8` / `#FBBF24` / `#F87171` |
| 圆角 | 外框 20，卡片 14–20，胶囊 22 |
| 字号 | 主标题 46–52 / 段落标题 24–26 / 卡片标题 20–22 / 正文 19–20 / 辅助 18 |

## 三条硬规则

1. **文字不小于 18**。GitHub 会把 1200 宽的图渲染成约 900 CSS px，18 单位只剩约 13.5px，已经是最小可读字号；11–14px 的小字在 GitHub 上会糊成一片。
2. **不用 emoji 当图标**。图标一律用 24×24 视框的 `path` 画（`stroke-width 1.8`、圆头、`fill="none"`），避免不同平台 emoji 字形差异。
3. **只用静态 SVG**。不用 `<foreignObject>`、`<script>`、动画、外链图片或远程字体；背景光晕要裁剪到圆角画布内，否则四角会露出光斑。

另外每个文件都要带 `role="img"`、`aria-label` 和 `<title>`，图片加载失败时读者至少还能看到替代文本。

## 预览

```bash
# 需要 rsvg-convert（librsvg2-bin）或直接用浏览器打开
rsvg-convert -w 1200 assets/readme/hero-banner.svg -o /tmp/hero-1200.png
rsvg-convert -w 900  assets/readme/hero-banner.svg -o /tmp/hero-900.png
```

900 宽的那张更接近 GitHub 实际显示效果，改完务必看一眼：文字有没有溢出卡片、有没有和别的元素压在一起、缩小后还认不认得出。
