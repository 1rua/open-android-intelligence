# README 视觉资源

这个目录放 README 首页用到的三张静态 SVG。视觉语言与最新 App 图标同源：**复古未来主义航天工程档案**，融合瑞士国际主义排版与 20 世纪中期太空时代美学。黑白灰为主调，只有一种低饱和橙色作强调；所有图形只用 SVG，不依赖图片生成、外链字体或动画。

| 文件 | 用在哪 | 画布 |
| --- | --- | --- |
| `hero-banner.svg` | 首屏横幅：技术档案封面 + 轨道链路示意 | 1200 × 400 |
| `architecture.svg` | 「怎么工作」：设备 / Gateway 协议 / Agent 宿主的三层工程图 | 1200 × 600 |
| `security-model.svg` | 「安全边界」：四级审批轨迹 + 黑底负面规范面板 | 1200 × 480 |

## 与 App 图标的关系

三张图共用同一组品牌母题，来自 `assets/branding/oai_logo.svg` 与启动图标：

- **轨道椭圆**：一条倾斜约 17° 的细椭圆，穿过主体结构，代表设备与 Agent 之间的连接链路。
- **橙色天体**：图标右下角那颗橙色圆点，在图中代表链路终点（Agent 节点）。
- **同心圆与坐标轴**：图标字标的几何感延伸为工程制图基准线。
- **黑白高对比**：不引入第三种色相，橙色只做点状强调。

## 视觉方向

- 复古航天工程平面设计，融合瑞士国际主义排版与 20 世纪中期太空时代美学。
- 大面积留白、非对称网格、锐利结构框、发丝级标注线。
- 超粗几何无衬线标题，搭配微型等宽大写参数文字。
- 轨道弧线、同心圆、坐标十字、工程刻度、遥测数据和科学制图符号作为结构元素，不做装饰性堆叠。
- 局部使用复古半色调网点与极轻印刷颗粒；颗粒只铺在纸面背景，不覆盖反白面板。
- 不使用人物、照片、霓虹发光、复杂渐变、模糊或写实 3D。

## 字号与线宽

| 层级 | 规则 |
| --- | --- |
| 首屏标题 | 64，900 字重，`letter-spacing -1.8` |
| 章节标题 | 44，900 字重，`letter-spacing -0.8` |
| 栏目标题 / 卡片标题 | 20，700 字重 |
| 正文 | 18，400 字重 |
| 参数 / 遥测 / 脚注 | 18，等宽，`letter-spacing 0.8–1.4` |
| 结构框线 | 1.2 |
| 发丝标注线 | 0.8–0.9 |
| 轨道线 | 1.4 |

字号下限固定为 18。GitHub 会把 1200 宽的图缩到约 900 CSS px，18 单位只剩约 13.5px，已经是可读底线。不要为了塞入更多内容继续缩小字号，优先删减文案或增加留白。

## 版式规则

1. 画布外框固定在 `x=20 y=20`，内容从 `x=44` 起排；四角保留十字定位标记。
2. 页眉使用 `OPEN ANDROID INTELLIGENCE / ... ARCHIVE`、`TECHNICAL DOSSIER / SHEET 0x`、`REV 2.1.1 / 2026` 三段式结构，分隔线保持 1px 黑色。
3. 主体采用非等宽栏位与锐角结构框，不使用圆角卡片、胶囊标签或玻璃拟态。
4. 每张图至少包含一组工程线元素：轨道椭圆、同心圆、坐标十字、刻度线或半色调区域，但不得压住正文。
5. 黑白反白面板只用于负面清单或强结论，整组图最多一块。
6. 图标一律用路径或简单几何线绘制，不使用 emoji、贴纸或位图。
7. 每个文件必须带 `role="img"`、`aria-label`、`<title>` 和 `<desc>`。
8. 同一行文字之间必须留出至少 12 单位空隙；等宽参数文字使用 `text-anchor="end"` 贴右边界对齐，避免与左侧正文相撞。

## 技术约束

- 只使用静态 SVG：不用 `<foreignObject>`、`<script>`、动画、外链图片或远程字体。
- 只用系统字体回退栈：标题 `Arial Black / Inter / Noto Sans CJK SC`，正文 `Helvetica Neue / Arial / Noto Sans CJK SC`，参数文字 `JetBrains Mono / Roboto Mono / DejaVu Sans Mono`。
- 网点与颗粒使用 `<pattern>`，不得用大尺寸位图或半透明光晕模拟。
- 所有坐标与线条保持整数或半像素级别，确保缩放后边缘干净。

## 预览与检查

```bash
# 900 宽更接近 GitHub 实际显示效果
rsvg-convert -w 900 assets/readme/hero-banner.svg -o /tmp/hero-900.png
rsvg-convert -w 900 assets/readme/architecture.svg -o /tmp/architecture-900.png
rsvg-convert -w 900 assets/readme/security-model.svg -o /tmp/security-model-900.png

xmllint --noout assets/readme/*.svg
```

检查以下项目：

- 中文长行是否越过结构框，尤其是 18px 说明文字。
- 页眉三段文字是否互相重叠。
- 反白面板最后一行是否与面板底边贴死。
- 900 宽下微型参数文字是否仍然清晰。
- 轨道线与正文交叠处是否影响阅读。
- 橙色是否只出现在编号、节点与标题色条上，没有变成大面积背景。
