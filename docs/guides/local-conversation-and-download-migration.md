# 会话本地恢复与附件下载升级说明

> **适用边界**：本文件描述 Android 本地对话镜像在 Gateway Protocol v2.1 下的升级与恢复行为，
> 适用于仍连接独立 Gateway 聊天端点的既有部署。统一 OAI Core 不提供 `/conversations` 聊天路由，
> 会话改由 `/open-android-intelligence/v2/agents` 原生会话面承载，其请求预算、幂等回执与
> 宿主能力边界见
> [架构事实基线](../architecture/2026-10-26-oai-core-architecture-baseline.zh-CN.md) 与
> [统一 Core 迁移方案](../plans/2026-10-25-unified-core-migration.zh-CN.md)。
> 本地镜像、附件下载与清理规则本身不因本次重构改变。

这次升级使用新的附件事件核心 Schema。配套版本为 Android 2.1.1、Hermes 插件 2.1.1、OpenClaw 插件 1.0.2，核心摘要是 `sha256:63223ba149355032800eeae8a9f0827d542bbde7ca9e4eeb19f93df30e7febde`。最终源码固定值、CI 和 APK 下载入口以本轮交付报告为准。只升级手机或插件会在登录协商时得到 `PROTOCOL_INCOMPATIBLE`。

先取得匹配 APK，再在维护窗口更新所使用的 Gateway 插件和 App。保留宿主状态目录、原账号数据库、主密钥、设备配对、手机账号和安装签名；升级无需新建账号、清除 App 数据或重新配对。插件更新后按宿主正常流程重新加载。固定调试签名 APK 可以覆盖相同签名的既有调试安装，发行签名的安装仍需相同发行身份。

App 第一次进入已保存账号时，先核验旧加密文档，再用一个 SQLite 事务迁入消息、发送身份、草稿、批次、修订、删除记录和游标。成功后新数据库成为唯一写入路径，旧密文移至同一私有范围下的复核目录；失败保留原数据并报告，不能以清空资料绕过失败。数据库和媒体原件位于不参与系统备份的私有目录，继续按 Gateway、账号和安装实例隔离。

第一次打开某个旧会话时，App 获取其完整历史，并在后台补存仍可读的原件。登录不会自动下载所有未打开会话。以后进入已同步的会话，先恢复双方消息与已有原件，后台再更新。已保存原件不按时间或固定配额淘汰；空间不足会提示保存失败，请用户主动整理手机空间后重试。

用户附件在发送消息前采用已核验的手机暂存字节，先保存发送身份和原件，随后提交网络请求。结果未知时沿用原身份查询；暂存过期后可以从持久原件恢复本地源，不能直接生成新消息身份重发。Agent 附件由宿主先采用到持久历史原件区，再发出附件事件，App 将已知附件加入可恢复的后台保存任务。升级前手机与宿主都已丢失的字节无法找回，附件卡片仍显示元数据及“原件不可用”。

三个附件入口统一使用“下载”。下载优先读取核验过的本地原件，保存为普通文件到 `Download/OpenAndroidIntelligence`，保留合法中文文件名和扩展名，同名由系统避让。写入期间文件保持未发布，长度和 SHA-256 核验完成后才显示成功；失败或主动取消回收本次未发布条目，恢复失败保留重试记录，不能挡住其他正常下载。该流程遵循 [Android 官方共享存储指南](https://developer.android.com/training/data-storage/shared/media) 和 [媒体回收状态定义](https://developer.android.com/reference/android/provider/MediaStore.MediaColumns#IS_TRASHED)。

退出登录锁定私有内容。移除账号、解除配对和远端明确删除按既有范围清理私有消息、预览及原件，不会修改用户已下载的公共文件。新设置界面移除“加密离线媒体”和配额开关；App 私有资料的加密保护继续生效。
