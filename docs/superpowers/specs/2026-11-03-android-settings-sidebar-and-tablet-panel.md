# Android 设置侧栏与平板适配

日期：2026-11-03。本文是设计与验收要求，不代表实现、自动化测试或设备验证已经通过。

## 背景与范围

现有设置通过 `ModalBottomSheet` 从底部弹出，设置内容的纵向滚动与下拉关闭手势容易冲突。本次要求将设置改为左侧侧栏呈现，保留既有设置页面、子页面路由、表单和业务逻辑；不通过调整底部弹层的拖动阈值规避问题。

范围仅包括 Android 客户端界面和必要的导航状态管理，不修改 OAI Core、Gateway 插件或通信协议。既有 Material 3 配色、排版和设置功能保持不变。

## 布局与导航

### 手机与紧凑窗口

- 手机端采用全屏侧滑设置页面：点击设置时，设置界面从屏幕左侧向右滑入（起点 `translationX = -screenWidth`，终点 `translationX = 0`），退出时向左滑出（起点 `translationX = 0`，终点 `translationX = -screenWidth`）。
- 设置页面覆盖整个应用窗口，宽度为当前窗口的全部可用宽度，高度填满整个应用内容区域，不沿用 320dp 抽屉宽度，右侧无残留会话、遮罩或空隙。
- 设置内部所有子页面同样使用全屏宽度，状态栏、导航栏、屏幕旋转及分屏正确适配。
- 设置内容支持正常上下滚动，纵向滑动不触发误关闭；支持系统返回与界面返回操作。

### 平板与宽屏

- 沿用 `WorkbenchScreen` 根据可用窗口宽度进行的判断：达到 `Dimensions.ExpandedWindow` 时使用宽屏布局，当前断点为 840dp。
- 打开设置时在原固定侧栏位置原位平滑切换替换会话列表，不弹窗、不叠加侧栏。侧栏宽度严格等于 `Dimensions.DrawerWidth`，当前为 320dp，高度填满可用侧栏区域。
- 右侧会话保持可见且原有布局、滚动位置、输入草稿和状态不变，不重新加载。退出设置恢复会话侧栏。
- 设置列表、卡片、按钮、输入控件及所有子页均应适配 320dp 宽度；文字应能换行或适当省略，不得溢出或遮挡操作控件。
- 窗口缩放、旋转或分屏跨越断点时，保持正在使用的面板及其相关状态，不出现双侧栏、内容重叠或状态丢失。

### 返回与入口

- 统一区分会话侧栏和设置面板状态，避免多个抽屉状态同时显示或争夺手势和返回事件。
- 设置子页面先执行已有内部导航返回；只有在设置根页才退出设置面板。从会话侧栏进入时，根页返回恢复会话侧栏，紧凑窗口保持抽屉展开；从登录页等其他非会话侧栏入口进入时，返回原页面。
- 遮罩点击和横向关闭手势继续关闭抽屉；系统返回和设置页面内的返回优先遵守上述导航层级。
- 使用现有 `SettingsScreen`、`SettingsViewModel` 和设置路由，不另建独立设置导航系统。设备能力授权、OAI Core 管理与插件设置等功能保持可用。

## 模块边界与安全区

`WorkbenchScreen` 位于 `conversation-ui` 模块，设置实现位于 App 模块。通过可组合内容插槽和状态回调集成：App 可依赖 `conversation-ui`，`conversation-ui` 不得反向依赖 App，也不得形成循环依赖。不同入口只在各自可见页面的宿主中承载一个抽屉。

状态栏、底部导航栏、横屏安全区和 IME（输入法）由宿主与内容明确分工；同一份 inset 只消费一次。使用 M3 抽屉组件的默认安全区处理时，内层页面不得再次重复补偿同一部分；固定侧栏没有相应父级消费时需补足安全区。输入法出现后，表单输入项与可操作区域仍须可见、可滚动且可触达。

## Material 3 动效与交互

- 优先使用 Compose Material 3 原生抽屉及其动画、手势和遮罩机制，不为抽屉开合自行硬编码时长或插值曲线。
- 横向拖动时抽屉位置实时跟随手指；松手后按位置和速度平滑完成展开或关闭。快速重复操作、反向拖动和系统返回时，动画应可中断并从当前位置连续过渡，不闪烁、不跳变。
- 从会话侧栏进入设置时，在同一容器内使用符合 M3 导航语义的内容过渡；宽屏只切换左侧内容，右侧会话不随之抖动。
- 设置内部页面使用符合前进和返回语义、方向相反的转场；系统和组件支持时支持预测性返回手势。设置根页与子页的返回优先级不得互相抢占。
- 遵循系统动画缩放及应用的减少动态设置：适当弱化位移与缩放等效果，同时保持布局、交互和最终状态正确。

## 待验证清单

以下均为验收目标，不表示已经通过。由 CI 自动化测试及具备相应条件的设备或模拟器共同验证：

| 场景 | 待验证行为 |
|---|---|
| 手机设置抽屉 | 从左侧连续滑入、向左关闭；手指跟随、松手后的吸附、遮罩同步、快速反向及点击遮罩关闭正常 |
| 滚动与设置导航 | 连续快速纵向滚动不关闭；各级设置子页先返回上一级，根页按入口返回会话侧栏或原页面 |
| 平板固定侧栏 | 设置替换原侧栏且精确为 320dp；右侧会话的宽度、滚动和输入状态不变；控件与文字不溢出 |
| 响应式变化 | 旋转、分屏及跨越 840dp 断点时，面板状态正确、没有双侧栏或内容重叠 |
| 入口与原有功能 | 登录页、离线模式、其他设置入口以及设备能力授权、OAI Core 管理和插件设置无回归 |
| 安全区与无障碍 | 状态栏、导航栏及键盘出现时内容不重叠或重复留白；触摸目标、无障碍语义和系统返回可用 |
| 动效设置 | 普通和减少动态模式下，页面前进、返回及中断恢复正确；支持条件满足时验证预测性返回 |

自动化测试应覆盖可观察的布局与导航状态；跟手效果、实际窗口变化、软键盘和无障碍冲突还需在相应设备或模拟器上检查。尚无运行证据的项目应明确记录为待验证。
