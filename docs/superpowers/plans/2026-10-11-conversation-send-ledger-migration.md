# 加密对话发送记录迁移说明

日期：2026-10-11。与 [缺陷修复计划](2026-10-10-conversation-bugfix.md) 一起实施。

## 保存边界

保留现有 `conversation-mirror-v1` 文档范围及账号密钥，范围仍包含本地资料、Gateway、账号和安装身份。新增 `send-atoms:<conversationId>` 加密文档，与纯远端 `timeline:<conversationId>` 分开保存。每个发送记录包含会话、客户端和可选远端身份、原始时间、正文及附件元数据、批次归属、本地提交状态、Agent 状态修订、内容修订和删除屏障。预览字节不进入工作台检查点。

普通退出锁定并保留这些数据。解除配对、移除本地账号仍沿用原有授权和清理流程；本轮没有新增权限或改变账号清理语义。

## 旧检查点迁移

读取版本 1 的工作台检查点时，按明确消息身份迁移仍可读的用户消息、未决单次提交和冻结批次；保留草稿、附件、事件身份和重命名标记。只有远端 ID 的旧消息保存为按会话的 `legacy-sent` 记录，不制造客户端身份。

迁移先写全部新发送记录和旧消息保留记录，全部成功后才保存版本 2 工作台检查点。中途失败时旧检查点仍标记版本 1，下次读取按同一身份继续迁移；已写记录按最新修订合并，不重复产生消息，也不覆盖较新的 Agent 状态。附件分块 V1 格式及账号密钥均无需迁移。

## 恢复与重试

重启后未确认的 `PREPARED` 发送显示为 `OUTCOME_UNKNOWN`，保留原身份、内容与时间。读取远端空快照只更换远端基线，不删除本地提交。事件及回执写回它们所属的会话，不受当前显示会话影响。

恢复操作由用户点击确认。查询以原 `clientMessageId` 和原会话执行；已受理的请求恢复远端 ID，不再次调用发送。查询失败保持未知结果；批次只有全部明确不存在才以原消息和批次身份重试，部分成员受理时保持待确认。

远端删除事件按内容修订建立删除屏障，移除发送正文、旧检查点与保留快照中的对应副本，媒体删除身份可供中断后继续清理。较旧内容事件、迟到 HTTP 回执和空快照均不能使已删除正文重现。

## 兼容与回退边界

此迁移只改变 Android 本地检查点，不改变 Gateway Protocol 2.1、核心 Schema、远端账号目录或配对材料。旧附件仍可用原读取器解密。版本 2 检查点由新应用读取；需要回退 APK 时应先核对该版本是否理解版本 2，不能通过清除账号数据来强行回退。

自动回归覆盖旧检查点可重试迁移、账号隔离、空快照、非活动会话事件、状态与内容修订、删除屏障、迟到回执、原时间及附件元数据；具体结果见所属仓的修复报告及证据目录。手机最终验收由用户完成。
