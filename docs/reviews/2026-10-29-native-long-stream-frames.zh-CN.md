# 长回复帧传输回归

真实回环 HTTP 测试将约 600 KB 的中文最终快照分成不对齐 UTF-8 字符的 4093 字节网络块。原 `RemoteSessionAdapter._send` 使用 aiohttp 默认逐行预算，在本次依赖版本中超过 524288 字节即抛 `LineTooLong`，最终回复无法通过 Core。测试修复前为 1 failed、1 passed。该证据定位在 Core 到 Adapter 的传输读取，不代表 Compose 卡顿或真实手机网络已被测量。

修复沿用 aiohttp 标准 `readline`，给原生事件设置明确的 8 MiB 上限，与已有 Codex 原生读取预算一致，并低于 Android SSE 的 10 MiB 上限。普通网络块不要求与字符或帧对齐；身份、正文和终态按原顺序透传。超过上限时返回明确的 `AGENT_STREAM_TOO_LARGE`，不猜测执行结果，不重发消息；格式异常中可能带有正文前缀的原始异常不进入公开错误或普通错误日志。

回归覆盖长中文 done 快照、无终态 EOF 不重发，以及缩小测试预算后超限错误的脱敏。该修改保障支持预算内的传输正确性；真实跨机器分段耗时、代理缓冲与手机渲染延迟仍需通过各阶段诊断测量。
