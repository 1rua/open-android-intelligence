# OAI Core 账号与管理认证重构交付记录

基线：`dev@f5bd4bd6`。工作分支：`feature/oai-core-zero-config-admin-auth`。本记录区分已实现、自动化通过和仍需环境验收，不能用测试替身代替真实部署。

## 变更

- 账号级登录与目标设备分开；CLI/MCP 支持无设备登录、动态选路和自动刷新。已接受请求固定设备与配对代次，歧义返回本人设备列表。
- 实例身份库集中管理账号、角色和认证版本；新账号默认普通用户。管理员管理授权限时限权，旧本机确认/root/桥令牌不能代替账号认证。
- 2FA 默认关闭，只在服务端开启后执行验证器/备用码挑战。Android 登录支持旧设备私钥证明和首次绑定，正常续期不重复验证码。
- 安装、setup、卸载和兼容管理入口接入真实认证；配置候选、备份、锁、journal、回滚与审计保留。旧账号迁移指定现有账号验密，保留 ID/密钥/历史并阻止旧写入者。
- Hermes 注册核验 Core 实例密钥，专属原生空间由桥生成，账号隔离、请求防重放和创建中断恢复有自动化覆盖。
- 更新 README、CLI/安装说明、术语、ADR 和 Agent 使用指南。

## 仍需确认的边界

- 当前未完成 Android 真机/ADB 设备调用验收；不清除真实手机数据、不读取真实短信、不将模拟数据当真机证据。
- Android 离线退出已保留本机退出屏障，但远端注销待同步日志仍需闭合；CLI 已有受保护待撤销记录，不能把两端完成情况混为一谈。此项作为草稿 PR 阻断，不声称退出后远端凭据已即时撤销。
- 共享 DSH/Codex 会话不注入个人常驻凭据；宿主无法隔离回合时不自动继承个人设备身份。独立 CLI/MCP 账号登录可直接调用。
- Hermes 首次跨安全边界信任需管理员确认 Core 公钥；此后新 Core 账号使用专属空间，不再逐用户手填映射。生产宿主安装、信任清单和服务重启需部署环境验收。
- 全部恢复证明或身份登记损坏时失败关闭并保留现场；当前恢复命令不宣称可从任意损坏身份库无损重建，也不会生成替代主密钥。
- 安装升级跨账号库、配置文件及服务是可恢复阶段，不宣称天然单次事务。操作系统/本机程序属于受信部署边界，应用认证不抵御已能任改二进制或磁盘的恶意 root。

用户要求停止扩展测试范围后，收尾采用已有自动化证据，仅修复已发现阻断，不继续反复全量回归。PR 应披露以上未验证项，不能把本记录概括为完整生产验收。
