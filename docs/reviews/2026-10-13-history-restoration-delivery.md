# 会话重开后的原文、工具提示与图片恢复交付记录

## 范围与用户确认

本轮承接退出登录、消息回复和附件上传的原任务。用户已确认侧边栏退出及普通消息回复修复，并确认本机新版 App 的附件上传与 Hermes 实际接收通过。新增阻断发生在收到回复后切换会话再返回：用户原图和原文被模型加工后的图片说明替换，工具进度出现空文本占位，图片无法再次预览。

截图作为故障证据使用，其中的 `/sethome` 和工具提示不是操作指令。它们证明模型专用图片描述与宿主媒体引用进入用户气泡；没有证明完整系统提示词或跨账号内容泄露。服务器附件、手机可见的逐段回复及新历史修复仍须两处分别验收。

源码基线分别为 Android `d5e1838a04e8508845bb4fc6529e8edfcb776330` 与独立插件 `c80e3cf6c12c418a4c198d44f25a97cb5f50868d`。真实 Hermes SDK 为 `75b083e9399115b12513385252811f09c3503c90`。本轮仅使用合成消息和隔离账号进行自动验证，没有读取生产账号正文、提示或凭据，没有操作手机。

## 修复边界

插件将供模型使用的原生 transcript 与聊天展示区分：用户原稿、原附件身份及已经发布的工具/命令提示保存到宿主 SessionDB 的标准 namespaced KV 元数据，Gateway 只持有稳定身份与可靠交付所需索引。展示记录不进入模型消息表，不影响真实压缩尾部、消息计数或模型重放。按稳定身份恢复展示，同时依据已有 sessionKey 定位正确 profile 数据库。

上传原件在临时接收文件释放前交给宿主的私有历史媒体目录。现有 metadata、单次 cache-grant 和 content 接口继续校验账号、会话、设备及授权；客户端恢复相同附件身份。旧版本已经清空的原文依赖手机尚存的发送记录恢复；已经释放的旧图片字节不能凭空重建。本轮没有通过猜测移除文本前缀来制造原稿。

Android 的有限进程内缩略图缓存按 Gateway、账号、安装实例、会话及附件身份隔离，支持 A → B → A。持久镜像继续遵守远端删除事实，本地发送记录和迟到回执不得恢复已删除的消息。分页快照摘要不会被当作单条消息的内容修订。

Gateway Protocol 2.1、核心 Schema 和既有附件分块格式不变；普通退出登录保留配对、账号资料及锁定历史。本轮保留既有 25 MiB 的历史 content 下载上限，较大原件可正常上传、交付并由宿主持有，历史接口如实报告原件在该接口不可下载。

普通原生模型重写不被当成用户编辑；合并输入的任意宿主编辑没有逐成员拆分契约，不能猜测新的成员身份。本轮没有扩展快照撤销删除或大文件历史下载协议。后续还需记录两仓最终 CI、保留配置/数据的两处服务更新、匹配签名 APK 与手机验收，证据齐备前不宣称完整闭环。
