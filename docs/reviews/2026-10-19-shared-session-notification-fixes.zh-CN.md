# 会话、气泡附件与任务通知修复记录

PR #14 的后续 Codex 评论判断、并发与恢复边界修复及最新验证结果见[评审复核记录](2026-10-19-pr14-review-followup.zh-CN.md)。本文保留初始实现的原因及验证记录。

## 原因与修复

历史列表此前丢弃分页游标，气泡入口又只投影运行中的任务，因此两处无法展示完整历史。现在两处共用会话浏览器与账号级组织数据，遍历全部历史分页；默认按更新时间倒序，长按拖动会保存自定义顺序。文件夹、分类和顺序通过带版本比较的网关写入同步，冲突后重新读取服务端状态并有界重试原操作。加密本地镜像保存归档、组织结构、排序和历史版本；离线缓存缺少某个会话不能作为删除凭据。刷新列表继续遵守当前会话的手动标题保护。

新增 `conversation-management-v1` 协商能力。归档与删除等待 Agent 原生存储确认，Hermes 使用真实 SessionDB 并处理压缩链，OpenClaw 调用宿主会话生命周期 API；删除屏障阻止旧分页、检查点或事件回放重新导入会话。归档历史仍可阅读，运行中任务和待提交发送会阻止归档、删除。两个适配器只管理当前 Gateway 账号已有的可信绑定，不导入其它 Agent 聊天。

气泡工作台此前没有附件协调器，输入区也只有文本。现在主界面与气泡共用系统选择器、预览、校验、上传、重试、移除和发送逻辑，气泡保留独立草稿。选择器绑定会话、控制器和发送代数，避免切换或发送后加入错误草稿；旋转屏幕保留目标。真正关闭控制器时清理未发送的附件暂存，已接受的发送由会话继续持有。

通知此前把正文与状态共用时间先后判断，并在完成标记写入后拒绝后到的完整正文；节流任务也可能把终态覆盖为部分预览。现在正文与状态分别比较修订，终态强制刷新，旧异步发布不能覆盖新状态。账号级事件订阅不依赖当前打开的会话；断线恢复、过期游标和静默任务会触发有版本保护的完整历史核对。正常流式输出期间不重复扫描历史，终态正文采用有界退避重试。只能确认已空闲时使用“任务已结束”，不推断成功或补发历史完成提醒。

Android 16 默认只发布一张原生 Live Update。仅在系统确认用户选用了会话气泡时保留禁止在通知栏重复显示的气泡伴随通知；任务结束后移除 Live Update 并更新普通会话通知。Android 14/15 保留原有通知回退。长文本的运行态显示尾部，终态显示首尾及查看完整回复的提示；按 Unicode 码点裁剪，并将 UTF-16 长度留在框架截断上限以内，避免结尾再次被系统截掉。

## 配套部署

核心契约摘要已变化，APK 与网关需要配套更新。初始提交通过[配套补丁](../../gateway-contract/patches/conversation-management/README.zh-CN.md)交付；后续已同步到两个独立插件仓，主仓安装引用、协议及 Android CI 直接检出对应提交。当前固定版本、安装与验证结果见[插件同步记录](2026-10-19-gateway-plugin-sync.zh-CN.md)。

独立 Hermes 矩阵与原生矩阵分进程运行，避免 SDK 注册表改变模拟宿主用例的进程状态。大文件签名 HTTP 用例传输约 38 MiB 并验证完整摘要，单项超时为 15 秒，以容纳共享测试机器的 CPU 和 IO 争用。

Android 的两个 Full 变体各有 398 项测试通过；两个 Play 变体各有 395 项通过、3 项生产插件宿主测试按渠道条件跳过。会话数据的 Debug / Release 各 60 项通过，会话 UI 的 Debug / Release 各 312 项通过。全量 Gradle 检查完成 1,973 个任务，耗时 20 分 21 秒。

镜像恢复回归按界面串行调度控制器，并等待历史装载、发送接受和持久化完成；一次 `yield()` 不代表真实 IO 已完成。只使用假策略端口的设置页界面测试使用普通 `Application`，隔离生产启动的额外工作。弹窗与底部附件菜单的真实点击测试采用原生图形模式，并区分菜单项和会话行的合并语义。相关消息数量、删除、重启恢复、拖拽顺序和加密断言均保留。

文件夹编辑测试遇到 [Robolectric #8460](https://github.com/robolectric/robolectric/issues/8460)：指定超过 320dp 的窗口宽度时，弹窗内输入框可能持续请求布局。该用例采用 320dp 测试窗口，保留实际文本输入、空闲等待及全部管理回调断言；其它浏览器用例继续使用 411dp 窗口，附件菜单另覆盖 320dp 紧凑窗口的展开与点击。生产输入框的字体和窗口宽度未因此改变。文件夹管理器与编辑、删除确认框之间每次仅显示一个弹窗，取消编辑后返回管理器。

未进行 Samsung 真机验收，也没有将模拟框架测试等同于 Now Bar 兼容。官方 API、厂商设置边界与待执行的真机矩阵见[兼容性说明](2026-10-18-session-notifications-compatibility.zh-CN.md)。
