# 默认保存会话原件，用户下载时导出公共文件

本决定替代 ADR 0044 中“按 Gateway 手动开启、独立固定配额管理媒体缓存”的部分。完整本地镜像、账号隔离、远端编辑与删除权威、退出锁定及移除账号清理规则继续有效。

Android 默认持久保存已同步的用户与助手消息及附件原件。打开会话先展示已保存的双方消息，随后后台同步；已有历史在首次打开对应会话时补存，登录不自动下载全部历史原件。原件不按 TTL 或缓存配额淘汰，磁盘不足明确显示保存失败，不能删除已有原件来制造保存成功。

会话镜像使用平台 SQLite 与逐记录 AES-GCM，消息、修订、删除事实与对话游标在同一事务内提交。附件使用账号范围内的分块加密文件，元数据及任务独立保存；用户发送直接采用已校验的本地暂存，Agent 附件使用受认证、对话绑定的宿主原件读取接口。关键落盘操作可等待完成，网络提交和事件确认不得越过未成功的本地事务。

SQLite 的单条密文按小块读取，避免合法大正文超出平台 CursorWindow；不通过扩大系统窗口或降低附件、正文契约规避。按目标记录和会话解密，明文内容缓存受最大堆内存的 1/64 预算约束；预算可由测试注入，淘汰只释放临时内存，不删除持久记录。账号打开不再先解密所有会话正文，数据库读写与解密、编码由 IO 端口完成，界面同步读取已恢复的内存投影。

“下载”是用户明确发起的公共文件导出。使用 MediaStore.Downloads 保存原始普通字节至 Download/OpenAndroidIntelligence，核验完成后发布；同名不覆盖，失败或主动取消只回收本次尚未发布的条目。已公开文件归用户管理，退出登录、解除配对、移除账号和远端消息删除均不修改它。私有下载恢复日志随本地账号范围清理。

旧镜像和已手动保留的媒体事务迁移，失败保留旧数据；成功后只有新路径继续写入。已有明文导出、活动账号、配对、刷新凭据不因升级重置。手机与宿主都已丢失的旧字节不能恢复，仍保留附件信息并明确提示原件不可用。

内部加密保护继续有效，设置和下载界面不再暴露“加密离线媒体”或人工“保留离线副本”。不进入 Android 云备份；开发者信任模式的既有边界继续有效。
