# 保留极简 Android 宿主与不可插件化的平台内核

> **2026-11-13 目标范围**：最小 Android 宿主与本机内核权威继续有效；只连 HTTPS Gateway 及屏幕一律经插件入口的旧限制由 Remote 双角色和原生屏幕端口取代。 见[新总规格](../specs/2026-11-13-dsh-remote-architecture-refactor.md)。本次只更新文档，不宣称运行时代码已变更。

Android 宿主面向用户只保留 HTTPS Gateway 连接与对话、显式附件上传和插件管理，其余设备能力全部作为可安装插件提供。项目允许任何人制作和分发插件，但设备身份、本机授权、Android 权限代理、插件隔离、审计和紧急停用必须由不可卸载的平台内核掌握，因为开放插件不能同时成为自身权限的最终裁决者。平台内核的隔离承诺适用于默认受保护模式；用户明确开启开发者信任模式并运行同进程原生插件时，该插件被视为平台内核的一部分可信代码。该决定取代旧设计中由主 APK 直接组合通知、短信、通话记录和默认 Tailscale 能力的产品边界。
