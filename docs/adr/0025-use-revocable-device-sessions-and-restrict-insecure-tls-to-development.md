# 使用可撤销设备会话并将不安全 TLS 限于开发测试

Android 首次登录一个账号时输入密码，但绝不保存密码；验证成功后 Gateway 可以签发绑定账号与 Android 安装实例、可轮换且可撤销的刷新凭据。Android AccountManager 只保存账号显示与连接配置及秘密引用，实际刷新凭据由 Android Keystore 保护，允许应用重启和账号切换时自动登录。自动登录不自动产生后台同步或插件授权；只有用户已明确授予的后台同步可以在刷新会话后继续。退出登录采用本地优先完成策略：立即持久化退出屏障阻断自动恢复并清理本机凭据，随后发起旧 access session 的远端注销；服务器端设备级完整刷新凭据撤销不作为本地退出的阻断条件。密码重置撤销账号的全部刷新凭据。正式连接使用系统 CA 或用户明确确认并固定的私有证书公钥；真正忽略 TLS 身份错误的连接只允许本地或明确开发测试地址，持续显示警告，并禁止账号密码、刷新凭据、附件、后台同步、设备插件和任何敏感数据，Tailscale 也不豁免 HTTPS 身份验证。
