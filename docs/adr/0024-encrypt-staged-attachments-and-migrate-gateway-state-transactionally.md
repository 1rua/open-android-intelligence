# 加密暂存附件并事务迁移 Gateway 状态

附件以随机 ID 和有界缓冲流式写入加密暂存区，完成实际长度与 SHA-256 完整性核验后原子提交给 Agent 宿主；Gateway 不按字节数上限或 MIME allowlist 拒绝附件，媒体类型作为描述元数据透传，由 Agent 决定是否处理。宿主确认接收、上传失败、会话删除、配对解除或期限到期都会清理 Gateway 临时副本。Gateway 升级进入迁移模式：停止新入口、完成或取消在途事务、创建不可携带的本地恢复点、事务执行 Schema 迁移并验证约束、游标、队列和密钥，成功后恢复服务，失败则恢复旧版本与数据；不可逆迁移必须阻止旧插件版本重新启动。
