# 配置即发现边界，在线状态来自宿主探测而非配置推断

OAI Core 只发现管理员在 `agents` 数组里显式声明的 Agent 实例；不遍历其他用户 HOME、
其他服务或未注册实例。每个实例的在线状态由对宿主的真实握手或查询得出（超时视为离线），
不由"配置存在"推断；宿主不支持的能力在服务端与 App 同时禁用。

选择显式配置而不是自动扫描，是因为原生会话分布在不同宿主的账号目录与进程边界内，
任何"自动发现"都会变成跨账号越权读取的入口。代价是新增宿主要改一次服务端配置；
这换来的是发现结果可审计、可回滚。会话接入范围本身由宿主事实决定
（见 ADR 0057），配置不能把 Hermes 声明成部署共享。
