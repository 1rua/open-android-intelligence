# 将现有设备能力发布为无特权参考插件

> **2026-11-13 目标范围**：离散数据插件的签名、沙箱与最小权限继续有效；旧配对授权不继承，屏幕高频路径改由仍受本机内核约束的 Kotlin 端口承载。 见[新总规格](../specs/2026-11-13-dsh-remote-architecture-refactor.md)。本次只更新文档，不宣称运行时代码已变更。

通知、短信和通话记录分别迁移为独立签名的受保护插件，使用平台内核在有限宿主能力包络中导出的安全原语。它们与社区插件遵守相同包验证、启用、配对授权、资源、审计和卸载规则，不随 App 新安装自动启用，也不因官方作者身份获得隐藏权限；其他旧设计能力在拥有独立契约和验收测试前不创建空占位插件。
