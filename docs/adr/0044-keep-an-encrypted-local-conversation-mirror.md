# 在 Android 保存完整加密对话镜像

媒体的可选保留与固定配额策略已由 [ADR 0053](0053-persist-conversation-media-and-export-user-downloads.md) 改为默认持久保存；本文其他镜像、隔离和账号生命周期决定继续有效。

Android 为每个 Gateway、账号和安装实例保存可离线阅读的完整加密对话持久镜像，包含文本、独立发送单元与合并批次关系、消息状态、命令、工具结果和附件元数据；Hermes/OpenClaw 的 Agent 工作状态仍是跨设备长期权威，远端编辑与删除通过结构化事件更新本地镜像，本地旧副本不得覆盖远端事实。用户按 Gateway 明确开启且受独立配额管理的本地媒体缓存，与仅为当前草稿和待提交意图服务的本地附件临时暂存是两种不同数据；第一阶段不在缺少用户提交意图时自动发送，离线只保存加密草稿，但用户已点击提交后可以等待附件验证完成并自动完成同一次已确认发送。退出登录保留但锁定镜像，解除配对、移除本地账号或删除 Gateway 账号按各自动作范围清除镜像、临时暂存和媒体缓存。镜像不进入 Android 云备份，未来只通过用户显式发起、范围可选且端到端加密的导出迁移；启用 Developer Trust 表示原生插件也可能接触该本地数据。
