## 变更

同一 Android 安装连接不同 Core 时，旧能力许可按 Core/账号分区，导致切换后设置不一致。本 PR 将持久能力策略收敛为安装实例单份；Core 负责合法设备绑定、路由和可靠交付。账号、主密钥、配对、会话、历史、附件及系统权限继续保留。

```text
合法设备请求 → Core认证/路由 → Android全局策略/范围/系统权限 → 执行及交付前复核
短信/通知事件 → 独立主动范围 → Android加密队列 → 已选端点 → 逐端消费ACK
```

- 能力总开关、三级模式和范围由 Android 裁决；临时批准支持本次或限时，执行及敏感结果交付前重新检查。
- 短信、通知的被动范围和主动推送独立，推送默认关闭；本地加密队列按稳定端点逐端确认并处理到期、撤销与恢复。
- 通知沿用已安装应用列表，支持搜索、正选/反选和草稿；短信采用默认全部、关键词、电话号码，正文外发独立控制。
- 取消通知推送256应用数量上限，未设置其他应用数量上限；移除每插件“恢复上一版本”按钮；主动推送菜单复用同级设置容器及原进退转场。
- UI功能与文案保真、禁止自行定义用户未明确要求的产品设计，已写入spec、CONTEXT、设置规格、指南及AGENTS.md。
