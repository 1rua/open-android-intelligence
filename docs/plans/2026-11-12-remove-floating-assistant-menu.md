# 移除会话更多菜单中的浮动助理

关联需求：#156。初始开发基线为 `dev` 的 `eecbb06fbe591591bc367e08b8fd0f98b0e7e23d`，提交前已无冲突地同步到 `26c0e5c92745e3374b88c293d27677f200efff0f`，最终独立审查以同步后的基线为准。

## 目标与边界

删除会话右上角「···」菜单中的「浮动助理」，清理该菜单项的点击事件及直接关联且不再使用的代码。其他菜单项、默认数字助手、Android 原生消息气泡和其他入口的助手能力必须保留。

保持现有 Material Design 3 菜单样式和动画，不增加提示、占位菜单或替代入口，不修改其他菜单文案和行为。

## 验收

1. 会话更多菜单不再显示「浮动助理」。
2. 其他菜单项正常显示、点击和执行。
3. 其他入口的助手功能不受影响。
4. Android 编译及相关测试通过。

## 验证方式

先核对入口、事件及状态的完整引用关系，保留助手共用实现。执行 `npm run test:fast`、`npm run test:pr`，结合现有菜单、助手及消息气泡回归测试验证；完整构建由 PR CI 执行。代码完成后按固定基线安排独立规范审查和需求覆盖审查。测试与审查证据随后记录到本文。

## 实现范围

- `WorkbenchScreen.kt`：移除「浮动助理」菜单项及助手回调参数，保留重命名、附件库、设置的原有菜单组件与点击逻辑。
- `MainActivity.kt`：清理该入口独占的显示开关、浮动面板装配和圈选投屏授权；录音状态继续直接传给工作台输入坞。
- `FloatingConversationPanel.kt`：基线中仅由上述菜单入口调用，随入口移除其专用面板和私有消息列表实现。
- 资源和测试清单：移除浮动菜单、面板和面板投屏授权专用字符串，以及失效的文案迁移记录；将原浮动面板 Journey 改为会话更多菜单验收，保留其他 Journey。

默认数字助手的 `assistant-holder`、原生气泡的 `BubbleConversationActivity`、远程截图授权和底层截图能力实现均保留。通用助理表面、圈选组件及其既有测试不纳入本次组件库清理。
