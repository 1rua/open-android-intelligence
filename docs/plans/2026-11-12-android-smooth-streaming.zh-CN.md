# Android 流式正文呈现与触觉反馈

关联需求：#160。固定设计基线：`26c0e5c92745e3374b88c293d27677f200efff0f`。

## 已确认行为

覆盖主聊天、气泡窗口、系统助理。完整接收文本继续作为同步、复制和落盘事实，UI 仅保存临时展示偏移。普通正文与执行过程的最终回答共享调度；工具卡、附件、消息身份、列表键与滚动行为保持原有逻辑。

首个非空实时内容立即开始展示，不等待积攒。连续曲线初值为每秒 40 字素加待显字素数除以 0.35 秒，速度约 120ms 平滑过渡，正文提交约 30Hz；终态目标约 250ms 排空。重复或旧修订不推进；历史恢复直接显示；活跃回复的追加型同步快照仅静默增加缓冲；非追加权威改写直接校正并清除旧动效。

Unicode 使用 Android ICU 字素边界，不拆代理对、组合字符、Emoji 与 ZWJ；已知不完整尾部保留，后续扩展最后一个字素时原位合并。

复用现有 Markdown 解析器并记录来源范围。新增文字按短期范围批次从 0.45 透明度约 120ms 渐入，最多 8 批；语法闭合与重排不重新渐入。缓存只保留解析器明确关闭并有顶层空行分隔的前置块，动画帧不触发解析。公式沿用现有 KaTeX。

光标使用正文容器独立绘制层与真实布局坐标，不向文本插入占位。位置可中断地平滑跟踪，拖尾约 160ms 衰减且限制在末端附近。滚动不产生轨迹，布局代次变化清理旧轨迹。减少动画仍保留吐字，只关闭渐入、位移和拖尾。

正常结束、取消成功和明确失败后排空已收缓冲；仅请求取消不提前结束。页面隐藏、切会话和销毁取消 UI 资源，网络与持久化继续，重开不重播。系统助理当前活跃回复的完整正文保护延续到终态，避免超过 32k 时被预算截断覆盖。

## 设置及触觉

仅新增「震动反馈」「输出时伴随轻微震动触觉反馈」两条字符串，在现有外观页面加入默认关闭的 Switch。复用外观偏好、原子持久化、备份与回滚。旧备份缺字段默认为关闭，备份摘要不改。系统助理经现有桥接即时接收偏好，不依赖跨进程 SharedPreferences 刷新。

触觉只由可见新文字推进触发；间隔随速度在约 100～150ms 之间变化，不排队补震。原生 KEYBOARD_TAP 尊重系统设置，无新增权限或服务。仅可见且获得焦点的入口触发，关闭设置、后台、隐藏和销毁立即停止。触觉副作用独立于正文重组。

## 验收与证据

状态测试覆盖 150 字突发、不均匀小块、积压、终态先到、取消、停顿、快照、重复、身份变化、所有 UTF-16 分割和最终全文相等。Markdown 对照完整解析，Compose 覆盖两种正文路径、真实末端、跨行、滚动、重排及旧文字稳定。

回归复制、选择、链接、附件、工具、审批、自动滚动、生命周期、设置、备份与助理 >32k 终态。触觉测试验证默认关闭、即时切换、限频、事件不积压及不可见停止。文案差异只允许指定两条。

运行关联测试与 Fast/PR 门禁。模拟器验证三个入口；同设备固定脚本至少三轮对照首字、排空、帧耗时、解析/重组次数及内存。实机触觉强度与系统兼容性必须单列实际执行情况，未执行不得视为通过。结果和风险写入 docs/reports。
