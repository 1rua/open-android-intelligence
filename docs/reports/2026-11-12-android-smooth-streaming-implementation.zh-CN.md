# Android 流式正文呈现与触觉反馈实施记录

关联需求：#160；PR：#161；目标分支：`dev`；任务分支：`feature/android-smooth-streaming`。设计及独立评审固定基线为 `26c0e5c92745e3374b88c293d27677f200efff0f`。初轮完整功能验收对应 `7e8a7393`，本轮审核修复功能头为 `860e2fe9`。本次仅保留这份最终文档，测试原始日志、JSON、截图及过程文档不随 PR 提交；相关测试代码继续保留。

## 实现

- **缓冲与吐字**：完整接收正文继续用于同步、镜像、数据库及复制；列表外注册器只维护当前回复的临时展示偏移。首个非空实时内容在下一可用帧消费，不等待积攒。正文提交约 30Hz，速度按每秒 40 字素加待显字素数除以 0.35 秒计算，约 120ms 平滑调整，终态以约 250ms 为内部排空目标。
- **身份及生命周期**：通过 Android 内部 LIVE/SNAPSHOT 来源与修订信息区分实时增长和恢复。重复、旧修订不推进，相同快照保持进度，追加型快照静默入缓冲，权威改写直接校正。正常结束、取消成功和明确失败继续排空；隐藏、切会话、销毁及重开不重播。正文容器重挂载以当前批次建立静默基线，后续新批次正常渐入与触觉。
- **Unicode 与 Markdown**：使用 Android ICU 字素边界保护代理对、组合字符、肤色和 ZWJ，续接最后字素不重复触觉。复用既有 Markdown 解析器，增加原文来源映射及保守前置块缓存；来源覆盖列表、表格、代码、链接、转义、实体和公式，语法闭合不重复渐入。短正文及首次长文初始化同步解析，后续可变尾段由单个可取消后台任务处理。完整事实更新仍可能触发既有同步解析；动画绘制帧不调用解析器。
- **渐入与光标**：新增范围约 120ms 从 0.45 渐入，最多 8 个活动批次；稳定叶节点不保留离屏合成层。独立 Canvas 使用真实文本布局和公式内容边界绘制细竖线及约 160ms 短拖尾，不向正文插入占位。布局变化重建坐标基准，滚动随共同父容器移动。KaTeX 使用最后有效直属 `.base` 排版块，无有效块时用内容 Range 兜底，避免满宽容器造成错位。
- **三个入口**：主聊天、气泡窗口、系统助理，以及执行过程后的最终回答共享正文呈现。分组、工具卡、附件和列表 Key 继续使用完整事实。气泡按末条实际高度增长补偿贴底滚动；助理最新活跃回复的预算保护延续至终态，防止超过 32k 的正文被截断。不修改后端协议、连接管理或数据库结构。
- **设置与触觉**：外观页只新增默认关闭的「震动反馈」，描述严格为「输出时伴随轻微震动触觉反馈」。复用外观持久化、备份、旧备份默认值、失败回滚及助理即时桥接。原生 `performHapticFeedback(KEYBOARD_TAP)` 由实际可见新增范围触发，约 100～150ms 限频；每批次仅检查一次可见性，离屏批次丢弃，滚动和重排不补震。遵循设置、系统触觉、焦点和生命周期，不新增权限、服务或振动库。减少动画保留吐字和静态末端，关闭渐入、位移及拖尾。

触觉参考 RikkaHub `90269e39dcf1beabf3066139c03f29162ebb082b` 的 `ChatMessage.kt:338-343` 和 `SettingPreferencesGeneralPage.kt:183-189`。参考实现通过内容变化、50ms 尾沿防抖及 KeyboardTap 触发；本实现改为跟随独立展示进度并节流，避免受网络分块节奏影响。

## PR 审核修复

## 未验证项目与风险

- 未连接实体手机，振动强度、节奏、系统关闭触觉、无马达及 OEM/省电兼容性未实机验证；模拟 View 回调不替代手感验收。
- 三个真实入口的账号网络完整链路、系统气泡创建和跟随交互、VoiceInteractionSession 生命周期及跨进程桥接仍需设备 E2E 验证。共享夹具不代表这些入口已完整验收。
- 真实 SSE 重连、取消确认、快照同步、进程重启后的设置及备份回滚，当前仅有状态、协议和 Robolectric 层覆盖。
- 性能尚未稳定达标，长 Markdown 仍有额外负担。解析、重组和分配次数未测，发布包、多设备、独立冷/热启动及长期内存行为未验证；不能宣称稳定 60fps、无性能回退或可见长文已在 250ms 内排空。
- 本地 `test:full` 未执行；完整发布回归交由发布流程。远端 CI 状态随提交变化，需按 PR 当前提交另行核对，不把运行中状态记为通过。
