# 这里的条目就是 PR 门禁运行的全部 App 单元测试，按功能域分节。
# CI 的 `android-app` job 编译一次、用 4 个测试 JVM 并行执行；
# 单域改动只跑 [core] 与对应域，跨域或无法判定时跑全部。
#
# `tools/test_ci_planning.py` 校验：每个类名真实存在、无重复、五域齐全，
# 且清单覆盖 apps/android/app/src/test 下的全部 *Test 类（漏掉即失败）。
#
# 完整回归（两个变体、无过滤）仍由 `:app:testFullDebugUnitTest` +
# `:app:testPlayDebugUnitTest` 覆盖。新增测试类必须同时加入本清单，
# 否则规划测试会报错。
